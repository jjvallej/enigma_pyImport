## 1. Definiciones y Explicación para Personal No Técnico

### ¿Qué es Google Cloud Composer / Apache Airflow? (Explicación Didáctica)
Imagine que la plataforma **ValleDATA** es una fábrica digital que necesita recopilar datos de diferentes entidades (como el DANE, la Gobernación del Valle del Cauca y agencias internacionales) de manera periódica.

Para que ningún funcionario tenga que ingresar manualmente a páginas web a descargar archivos Excel o CSV, se utiliza un **orquestador digital** llamado **Apache Airflow**, alojado en la nube de Google mediante el servicio **Google Cloud Composer**.

- **El Director de Orquesta:** Google Cloud Composer actúa como el director de una orquesta digital. Su trabajo es vigilar que los programas de recolección de datos se inicien a la hora exacta, supervisar que no ocurran fallas y notificar si un sitio web externo está fuera de servicio.
- **Beneficio Institucional:** Garantiza que la información pública esté siempre actualizada, disponible para los ciudadanos y protegida en la nube con los más altos estándares de seguridad y trazabilidad.
